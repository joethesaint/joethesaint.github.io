THE ENGINEERING

From school to the browser

A biogas project from my Agricultural & Environmental Engineering degree at FUTA, rebuilt as an interactive web experience.

The problem

Explore biogas production from a combination of cassava peel, pig excreta and poultry droppings.

The assembly

The report design connects a digestion tank, feeding funnel, gas piping, three filter housings and tyre-tube storage. Tap a component to inspect it.

The rebuild

I’m presenting the school assembly through a Three.js viewer: orthographic views, exploded animation, component picking and touch controls.

Design exploration

B follows the report. A is an illustrative concept; C is a proposed revision. D–F show reference system types.

Project report
Model scope

This is a visual reconstruction, not a dimensioned fabrication model. Fasteners and added fittings are illustrative. Proposal scores describe design completeness, not measured performance. Gas animation illustrates a route; configuration changes are visual transitions.
THE SOFTWARE

Inside the viewer

JavaScript + Three.js. Procedural geometry, local dependencies, and a responsive interface.

Interaction

Raycasting selects components. An orthographic camera switches between an equal-axis isometric view and a plan view. OrbitControls supports touch rotation and pinch zoom.

Animation

Component groups use stored assembly positions and explosion offsets. One toggle animates between them; reduced-motion preferences shorten transitions.

Performance

Repeated fasteners use instanced meshes. Mobile pixel ratio and shadow resolution are capped, animation is limited to 30 FPS on mobile, and hidden tabs skip rendering, and the scene only redraws when something moves.

Responsive layout

Touch controls stay outside the canvas. Component details become a bottom sheet on small screens; camera framing adapts to the viewport.
