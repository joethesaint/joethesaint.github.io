# Biogas demo release — 11 October 2026

Demo: https://joethesaint.github.io/biogas/

Publishing: push `main`; `.github/workflows/deploy.yml` checks and builds the project, then publishes `dist` to `gh-pages`. The public biogas files are copied into the production build.

## Included

- Clickable component labels, a process panel with an explicit Close action, and school-model step navigation.
- A research-linked conceptual route for upgrading biogas, checking gas quality, compressing/cooling and certified cylinder storage.
- A Nigeria planning estimate for the educational prototype; compression equipment is excluded.
- A single nine-second illustrative gas-flow cycle with Start/Stop controls and opening, flowing, closing and resting status.
- GLSL valve fading, corrected instance transforms, an on-demand render scheduler and capped device pixel ratios.
- Release fixes: anchor the liquid Close wrapper to the process panel, close other inspection panels when entering the process, and stop the process/cycle when manually changing explosion.

## Verification and its limits

JavaScript syntax, the existing arc-picker interaction regression, Svelte checks, lint, production build and whitespace checks passed. The gas shader's vertex and fragment bodies passed a standalone GLSL syntax check during implementation; that check supplied Three.js built-in declarations and omitted its output chunks. The renderer's final shader program has not been verified on a working GPU in this environment.

The new files and cache version were checked on the local preview. The production page and JavaScript must also be checked after the deployment completes.

Headless Chromium could not launch successfully in Termux, so no fresh desktop/mobile screenshots or GPU frame-time measurements were captured. Static control names and IDs were audited, but that does not prove runtime positioning or touch usability. No screenshot harness was added because the local browser cannot currently produce dependable captures; a functioning browser runner remains useful follow-up work.
